AI ADS PIPELINE02
How it works

The whole edit is code.

01 · INPUT
Drop screenshots + one sentence
Raw captures, any size. Context like “launch video for the rebrand.”
02 · STORY
Claude writes the narrative
Hook → scenes → end card. Mandatory PII pass: emails, wallet addresses, referral codes cropped or excluded.
03 · EDIT
React, not a timeline
The edit is a Remotion composition — motion design as typed code.
04 · SCORE
Music synthesized from scratch
Original UKG / deep-house generated in numpy, beat-matched to the cut. Zero licensing.
05 · QA
It checks its own work
Claude extracts frames, looks at them, fixes visual bugs, re-renders.
Output: 1080p MP4 in minutes. Any variant — 9:16, new copy, new language — is a re-render.
